# off. — 사진 · GIF 배경 제거

Vercel에 배포하는 React + TypeScript + Vite 웹 앱입니다. 캐릭터 보호·사진 AI는 이미지 파일을 서버로 전송하지 않습니다. **GPT AI**는 개인용 비밀번호로 보호된 Vercel 서버 함수를 통해 OpenAI 이미지 편집 API를 호출합니다. 기본 선택된 **캐릭터 보호**는 외곽선과 바깥 배경의 연결을 이용하고, **사진 AI**는 IMG.LY의 IS-Net 모델을 사용합니다. 두 방식 모두 별도 API 키 없이 브라우저의 Web Worker에서 처리합니다.

## 실행

Node.js 22 이상에서:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

브라우저 UI 테스트는 `npx playwright install chromium` 후 `npm run test:e2e`로 실행합니다. 시스템 Chromium을 사용한다면 `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`로 실행하세요. 캐릭터 보호·사진/GIF 영역 보정·가장자리 보정 테스트는 실제 Worker와 다운로드한 파일의 픽셀을 검증합니다. GIF는 프레임 선택·전체 적용·되돌리기·취소·재생 간격·반복 횟수도 확인합니다. 사진 AI의 추론 단계는 Worker fixture를 사용하며 AI 추론 품질을 검증하는 테스트는 아닙니다. 사진 AI 결과의 영역 편집에는 실제 보정 Worker를 사용합니다.

## Vercel 배포

1. [Vercel 새 프로젝트](https://vercel.com/new)에서 `BAEPPY/removebackground` 저장소를 Import합니다.
2. Framework Preset은 **Vite**, Build Command는 **npm run build**, Output Directory는 **dist**입니다. `vercel.json`에 설정되어 있습니다.
3. 기기 내 처리만 쓸 때에는 환경변수가 필요하지 않습니다. GPT AI를 쓰려면 아래 두 환경변수를 Production 환경에 등록한 뒤 **Deploy**를 누릅니다.

Vercel CLI를 쓰는 경우, 계정에 로그인한 로컬 터미널에서 `npx vercel --prod`를 실행합니다. 이 저장소에는 토큰을 넣지 않습니다.

`vercel.json`은 ONNX Runtime의 SharedArrayBuffer 지원을 위한 COOP / COEP 헤더도 설정합니다. 다른 호스팅으로 옮기면 동일한 헤더를 유지하세요.


### 개인용 GPT API 설정

Vercel 프로젝트의 **Settings → Environment Variables**에 다음을 등록합니다. 실제 키나 비밀번호는 GitHub 또는 채팅에 붙여 넣지 마세요.

| 이름 | 값 |
| --- | --- |
| `OPENAI_API_KEY` | [OpenAI에서 발급한 API 키](https://platform.openai.com/api-keys) |
| `APP_PASSWORD` | 본인만 아는 무작위 비밀번호, 최소 16자, 권장 32자 |

환경변수 등록 후 **Deployments → Redeploy**를 실행합니다. 사이트에서 **GPT AI**를 선택하고 `APP_PASSWORD`에 설정한 비밀번호를 입력하면 사용할 수 있습니다. 화면에는 OpenAI API 키를 입력하지 않습니다. 키는 서버에서만 사용하며 비밀번호는 브라우저 메모리에만 두어 새로고침하면 지워집니다. 두 변수가 모두 설정되지 않으면 서버가 유료 호출을 거부합니다. 키 설정 여부를 보여주는 표시는 실제 OpenAI 모델 권한·잔액 확인을 뜻하지 않습니다.

ChatGPT 구독과 API 사용료는 별도입니다. OpenAI 프로젝트에서 결제·사용 한도와 이미지 모델 사용 권한을 확인하세요. 본인만 사용하더라도 공개 URL에는 비밀번호가 필요합니다. API 키가 `VITE_` 환경변수에 들어가면 브라우저에 노출되므로 해당 접두사를 사용하지 않습니다.

`POST /api/background`는 OpenAI `POST /v1/images/edits`에 `gpt-image-1.5`, `input_fidelity=high`, `background=transparent`, `quality=medium`, `size=1024x1024`, `n=1`로 요청합니다. 이 모델은 투명 배경과 높은 입력 충실도를 함께 지원합니다. [공식 OpenAI 이미지 편집 사양](https://developers.openai.com/api/reference/resources/images/methods/edit)을 기준으로 구현했습니다. [Claude는 이미지 이해 모델이며 편집 이미지를 직접 반환하지 않으므로](https://platform.claude.com/docs/en/build-with-claude/vision) Claude 키는 지원하지 않습니다.

사진은 1회, GIF는 프레임당 1회 순차 호출하고 시작 전에 횟수를 표시합니다. 실패 시 유료 요청을 자동 재시도하지 않습니다. 취소하면 후속 프레임 처리는 중단되지만 이미 시작한 요청은 과금될 수 있습니다. 서버 시간 제한은 300초, OpenAI 요청 제한은 240초입니다. GIF 전체에 한 번의 서버 함수 제한을 적용하지 않고 프레임별로 호출합니다.

원본을 정사각형에 비율 유지·여백 추가로 넣고 AI 출력의 같은 위치에서 알파를 가져옵니다. 업로드 PNG가 크면 API 입력 분석 해상도를 낮춰 요청 본문을 Vercel 한도 안으로 제한합니다. 최종 RGB·원본 투명도는 원본 파일에서 가져오므로 AI가 새로 그린 얼굴이나 색은 사용하지 않습니다. 다만 생성 모델의 마스크가 피사체 위치를 잘못 잡을 가능성은 있어 원본 비교와 영역 보정이 필요할 수 있습니다. GPT로 얻은 반투명 가장자리에도 색 혼합 제거와 윤곽 정리를 적용합니다.

**GPT 영역 보정:** GPT AI로 처리한 결과에서 영역 편집을 열고, 평소처럼 대략 표시한 뒤 **표시한 곳 GPT로 보정**을 누릅니다. 마우스를 움직일 때마다 유료 요청하지 않습니다. 원본·현재 결과·색으로 표시한 가이드 3장을 보내고 표시 주변만 새 알파로 수정합니다. 복원은 알파를 늘리고 제거는 알파를 줄이며 직접 표시한 부분은 우선 반영합니다. GIF의 전체 적용 도중 API가 실패하면 이번 호출 묶음의 부분 결과를 적용하지 않습니다. 이미 처리된 호출 비용은 환불되지 않습니다. 되돌리기·취소도 사용할 수 있습니다.

로컬 API 개발은 `.env.example`을 `.env.local`로 복사해 값을 설정하고 `npx vercel dev`로 실행합니다. `npm run dev`와 `npm run preview`만으로는 Vercel 서버 함수가 실행되지 않습니다. 실제 키가 없는 테스트는 OpenAI 응답을 대체해 인증, 전송 형식, 원본 RGB 보존, 편집 범위, 오류 시 기존 결과 보존을 확인하며 실제 모델의 분리 품질 검증을 대신하지 않습니다.

## 기능

- JPG/JPEG, JFIF, PNG, 정적 WebP → 투명 PNG
- 캐릭터 보호: 단색 배경에서 외곽선 안의 흰 털·눈·입·이빨과 피부색 보존
- 사진·GIF 영역 보정: 원본을 보며 대략 표시해 복원/제거, 마지막 보정 되돌리기, 취소, 편집된 PNG/GIF 저장
- GIF 프레임 선택, 한 프레임 또는 모든 프레임의 같은 위치 보정, 움직임 미리보기
- 가장자리 혼색 보정: 단색 배경이 섞인 경계의 색과 투명도를 보정해 어두운 배경에서 흰 테두리 완화
- GIF → 투명 GIF와 부드러운 움직이는 PNG(APNG)를 함께 제공. 프레임 수, 원본 지연 시간, 반복 횟수 유지
- 윤곽 정리: 작은 배경색 잔여 점 제거, 불투명 계단 모양 모서리 완화. 가는 선과 흰 내부, 기존 반투명 픽셀은 보호
- GPT AI: 개인용 비밀번호, 예상 API 호출 횟수, 원본 색 보존, 명시적으로 요청한 영역만 GPT 재보정
- GIF의 부분 프레임, 투명 패치, disposal 2/3 복원 처리
- 파일 선택, 드래그 앤 드롭, 클립보드 붙여넣기
- 실제 결과를 이용한 전후 슬라이더, 미리보기 배경색 선택, 다운로드
- 진행률, 취소, 입력 검증, 처리 실패 안내, 반응형 한국어 UI

## 캐릭터 내부 보호

캐릭터 모드는 흰색을 일괄 삭제하지 않습니다. 테두리의 대표 배경색과 일치하는 영역을 찾고, 비배경 픽셀의 외곽선에서 틈을 보완한 뒤 캔버스 가장자리에서 연결된 배경만 투명하게 합니다. 외곽선 내부는 색과 투명도를 원본 그대로 유지합니다. JPEG의 가벼운 색 번짐을 허용하며, 원래 투명한 내부 구멍이나 반투명 픽셀은 덮어 채우지 않습니다. 이미 대부분 투명한 테두리는 원본 알파를 유지합니다. 작은 틈 보완만으로 몸통이 닫히지 않으면 그림 자체의 크기에 맞춰 더 넓은 틈을 보완합니다. 보완으로 생긴 영역은 안쪽과 바깥쪽의 거리로 나눠 흰 털이 과하게 깎이지 않도록 합니다. GIF에는 같은 처리를 각 프레임에 적용합니다.

캐릭터 보호·사진 AI에서 만든 사진/GIF 결과의 **대략 표시해서 자동 보정**에서는 마우스나 손가락으로 그린 선 전체를 보정 단서로 사용합니다. 시작점이 이미 복원되어 있더라도 중간과 끝의 새 영역을 처리합니다. 닫힌 윤곽은 자동 확장을 돕는 정보이며, 사용자 표시를 거절하는 조건이 아닙니다.

- 남길 부분 복원: 닫힌 캐릭터 영역은 함께 복원하고, 열린 윤곽이나 기존 자동 판정 밖의 영역도 표시한 경로와 주변을 원본 RGB·알파로 복원합니다.
- 남은 배경 지우기: 연결된 잔여 배경을 정리하면서 표시한 선 전체에도 제거를 적용합니다. 이전 보정과 반대되는 새 표시도 반영합니다.
- 반복 보정: 근처를 같은 방식으로 다시 표시하면 이전보다 넓은 주변을 계산합니다. 첫 계산에서 변화가 없으면 같은 요청 안에서도 범위를 넓혀 최대 세 차례 계산합니다. 멀리 떨어진 표시나 반대 방향의 수정에는 이전 확대 단계를 그대로 적용하지 않습니다.
- 경계 보완: 색상 차이가 큰 경계에서는 주변 확장을 억제하는 거리 기반 처리를 사용합니다. 큰 이미지는 최대 512px의 분석 격자를 쓰고, 표시 경로 자체는 원본 해상도에서도 적용해 가는 부위가 누락되지 않게 합니다. 열린 흰 영역이 바깥 배경과 이어져도 한 번에 캔버스 전체를 채우지 않습니다.
- 편집 이력: 명시적으로 수정한 영역과 표시 이력을 결과에 함께 보관합니다. 적용 후 다시 열어도 이전 복원·제거와 반복 보정 범위를 기억합니다. 되돌리기는 마지막 결과와 이력 1회를 함께 되돌리고, 취소는 적용하지 않은 편집과 이력을 버립니다. 새 파일 선택이나 페이지 새로고침 후에는 유지하지 않습니다.

기본 영역 보정은 피사체를 의미적으로 이해하는 AI는 아닙니다. GPT 영역 보정은 별도의 버튼으로 요청합니다. 경계가 불분명할 때에는 추가 표시가 필요할 수 있습니다. 사용자가 직접 표시한 경로를 우선하므로 원치 않는 곳까지 그렸다면 되돌리기나 반대 도구로 수정할 수 있습니다. 원본부터 투명한 픽셀에는 임의로 흰색을 채우지 않습니다. 원본 미리보기에도 체크무늬를 표시해 원래 투명도와 제거 결과를 구분합니다.

보정은 별도 Worker에서 실행되며, 초록·분홍 안내선은 저장 파일에 들어가지 않습니다. 적용한 PNG/GIF가 미리보기와 다운로드에 모두 반영됩니다. **원본 보며 표시**를 켜면 완전히 지워진 부위도 원본을 보며 복원할 수 있고, 표시 후에는 보정 결과로 돌아옵니다.

GIF 편집은 기본적으로 **이 프레임만** 보정합니다. 프레임 슬라이더로 다른 장면을 선택할 수 있고, **모든 프레임의 같은 위치**를 선택하면 각 원본 프레임의 색·윤곽을 분석해 같은 화면 좌표의 표시를 적용합니다. 움직이는 피사체를 자동 추적하는 기능은 아닙니다. **움직임 미리보기**로 확인한 뒤 적용하세요. 전체 프레임 보정도 한 번에 되돌릴 수 있으며 취소하면 적용 전 결과와 이력을 유지합니다. 재생 간격과 반복 설정은 원본에서 가져옵니다. 편집 Worker는 GIF를 순차 합성합니다. 양자화하기 전의 프레임을 PNG Blob으로 보관해 다시 열어도 부드러운 알파와 색이 소실되지 않으며, 모든 원본 RGBA 프레임을 한꺼번에 저장하지 않습니다.

## 흰 가장자리 보정

투명 영역과 맞닿은 좁은 경계에서 원래 단색 배경과 전경색이 섞인 픽셀을 찾아, 인접한 진한 전경색으로 색과 투명도를 복원합니다. 자동 배경 제거와 영역 편집 후 같은 처리를 거쳐 미리보기와 다운로드에 반영합니다. 반투명 마스크에는 투명도를 이중으로 곱하지 않고 원본 RGB를 기준으로 계산해 반복 편집에서 계속 어두워지는 것을 방지합니다. GIF는 보정된 RGB를 팔레트로 변환한 뒤 1비트 투명도로 저장합니다.

흰 털·눈·이빨 같은 실제 흰 픽셀을 전부 지우거나 윤곽을 일괄 축소하지 않습니다. 배경색을 확실히 추정할 수 없는 복잡한 사진이나 원래 투명한 이미지에는 임의의 흰색 제거를 하지 않습니다. 넓게 남은 흰 배경 영역은 가장자리 혼색과 별개의 영역 판정 문제이므로 영역 보정이 필요할 수 있습니다.

## 부드러운 윤곽과 APNG

배경색과 일치하는 4픽셀 이하의 작은 분리된 잔여 조각을 정리하고, 불투명한 계단 모양 모서리만 부드러운 알파로 바꿉니다. 어두운 수염·가는 선, 색이 있는 작은 장식, 흰 내부, 사용자가 명시적으로 복원한 픽셀은 보호합니다. 기존 반투명 경계를 반복해서 흐리게 하지 않습니다. 저해상도 원본의 디테일을 새로 만들어 내는 업스케일 기능은 아닙니다.

GIF는 1비트 투명도 때문에 이 부드러운 알파를 그대로 저장할 수 없습니다. 미리보기는 APNG로 보여주고, **부드러운 APNG 다운로드**와 기존 GIF 저장을 함께 제공합니다. APNG는 원래 시간 간격과 총 재생 횟수를 유지하고, GIF 편집 후에도 다시 만들어집니다. PNG를 정적 형식으로만 다루는 앱에서는 첫 프레임만 보일 수 있으므로 대상 앱의 APNG 지원 여부를 확인하세요. APNG 입력 파일의 재편집은 아직 지원하지 않습니다.

## 처리 제한

| 항목 | 빠르게 | 꼼꼼하게 |
| --- | --- | --- |
| 사진 AI 모델 | IS-Net uint8 | IS-Net fp16 |
| 사진 긴 변 | 최대 2,048px | 최대 4,096px |
| GIF 긴 변 | 최대 768px | 최대 1,024px |

공통: 파일 최대 20MB, 사진 4,000만 화소, GIF 프레임당 400만 화소·최대 120프레임. 작은 이미지는 확대하지 않습니다. 애니메이션 WebP/APNG는 프레임 손실을 막기 위해 거절합니다. GIF의 256색·1비트 투명도 제한으로 경계가 거칠 수 있고 프레임별 AI 추론 결과에 차이가 있을 수 있습니다. 투명도는 128 기준으로 변환합니다. 배경색 변경은 미리보기 전용이며 저장 파일은 항상 투명합니다.

## 네트워크와 데이터

캐릭터 보호와 영역 보정에는 AI 모델 다운로드가 없습니다. 사진 AI 모드의 첫 처리 시 `https://staticimgly.com/@imgly/background-removal-data/1.7.0/dist/`에서 모델과 WASM 실행 파일을 내려받습니다. 빠르게 모델은 약 40MB, 꼼꼼하게 모델은 약 80MB이며 실행 파일 다운로드가 추가됩니다. 사진 AI에는 해당 도메인에 접근할 수 있어야 합니다. 이후에는 브라우저 캐시가 재사용됩니다. 글꼴은 jsDelivr에서 내려받으며 실패 시 시스템 글꼴을 사용합니다. 분석·광고 코드는 없습니다. GPT AI를 선택한 경우에만 원본·결과·표시 이미지가 Vercel을 거쳐 OpenAI로 전송되며 OpenAI API 데이터 보관 정책이 적용됩니다. 이 앱은 파일을 별도 저장하지 않고 인증 정보나 이미지 본문을 로깅하지 않습니다. 결과와 원본 Blob URL은 새 파일 선택 또는 페이지 종료 시 해제됩니다.

처리는 별도 Worker에서 실행되며 취소 시 Worker를 종료합니다. UI의 모델 다운로드 수치는 현재 다운로드 중인 자산의 진행률입니다. GIF는 프레임을 한 번에 하나씩 디코딩·처리·인코딩해 디코딩된 모든 프레임을 메모리에 보관하지 않습니다.
