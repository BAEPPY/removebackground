# off. — 사진 · GIF 배경 제거

Vercel에 배포하는 React + TypeScript + Vite 웹 앱입니다. 이미지 파일은 서버로 전송하지 않습니다. 기본 선택된 **캐릭터 보호**는 외곽선과 바깥 배경의 연결을 이용하고, **사진 AI**는 IMG.LY의 IS-Net 모델을 사용합니다. 두 방식 모두 별도 API 키 없이 브라우저의 Web Worker에서 처리합니다.

## 실행

Node.js 22 이상에서:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

브라우저 UI 테스트는 `npx playwright install chromium` 후 `npm run test:e2e`로 실행합니다. 시스템 Chromium을 사용한다면 `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`로 실행하세요. 캐릭터 보호·PNG 영역 보정·GIF 테스트는 실제 Worker와 저장 결과의 RGBA를 검증합니다. 사진 AI의 다운로드·취소 UI 테스트는 Worker fixture를 사용하며 AI 추론 품질을 검증하는 테스트는 아닙니다.

## Vercel 배포

1. [Vercel 새 프로젝트](https://vercel.com/new)에서 `BAEPPY/removebackground` 저장소를 Import합니다.
2. Framework Preset은 **Vite**, Build Command는 **npm run build**, Output Directory는 **dist**입니다. `vercel.json`에 설정되어 있습니다.
3. 환경변수는 필요하지 않습니다. **Deploy**를 누릅니다.

Vercel CLI를 쓰는 경우, 계정에 로그인한 로컬 터미널에서 `npx vercel --prod`를 실행합니다. 이 저장소에는 토큰을 넣지 않습니다.

`vercel.json`은 ONNX Runtime의 SharedArrayBuffer 지원을 위한 COOP / COEP 헤더도 설정합니다. 다른 호스팅으로 옮기면 동일한 헤더를 유지하세요.

## 기능

- JPG/JPEG, JFIF, PNG, 정적 WebP → 투명 PNG
- 캐릭터 보호: 단색 배경에서 외곽선 안의 흰 털·눈·입·이빨과 피부색 보존
- PNG 영역 보정: 대략 표시한 곳의 윤곽을 따라 복원/제거, 마지막 보정 되돌리기, 취소, 편집된 PNG 저장
- GIF → 프레임별 배경 제거 후 투명 GIF. 프레임 수, 원본 지연 시간, 반복 횟수 유지
- GIF의 부분 프레임, 투명 패치, disposal 2/3 복원 처리
- 파일 선택, 드래그 앤 드롭, 클립보드 붙여넣기
- 실제 결과를 이용한 전후 슬라이더, 미리보기 배경색 선택, 다운로드
- 진행률, 취소, 입력 검증, 처리 실패 안내, 반응형 한국어 UI

## 캐릭터 내부 보호

캐릭터 모드는 흰색을 일괄 삭제하지 않습니다. 테두리의 대표 배경색과 일치하는 영역을 찾고, 비배경 픽셀의 외곽선에서 틈을 보완한 뒤 캔버스 가장자리에서 연결된 배경만 투명하게 합니다. 외곽선 내부는 색과 투명도를 원본 그대로 유지합니다. JPEG의 가벼운 색 번짐을 허용하며, 원래 투명한 내부 구멍이나 반투명 픽셀은 덮어 채우지 않습니다. 이미 대부분 투명한 테두리는 원본 알파를 유지합니다. 작은 틈 보완만으로 몸통이 닫히지 않으면 그림 자체의 크기에 맞춰 더 넓은 틈을 보완합니다. 보완으로 생긴 영역은 안쪽과 바깥쪽의 거리로 나눠 흰 털이 과하게 깎이지 않도록 합니다. GIF에는 같은 처리를 각 프레임에 적용합니다.

PNG 결과의 **대략 표시해서 자동 보정**에서는 처음 누른 곳을 영역 선택의 단서로 사용합니다. 선을 따라 정밀하게 칠할 필요가 없습니다.

- 남길 부분 복원: 같은 외곽선으로 연결된 캐릭터 영역 전체의 RGB와 알파를 원본으로 되돌립니다. 얼굴을 표시하면 같은 윤곽 안의 눈·입도 함께 복원합니다. 표시가 바깥으로 넘어가더라도 바깥 배경을 브러시 모양대로 덧칠하지 않습니다.
- 남은 배경 지우기: 외부 배경을 표시하면 윤곽 밖의 연결된 잔여 배경을 제거합니다. 닫힌 내부를 표시하면 원본의 색상 경계 안에서만 선택합니다.
- 복잡한 사진은 원본에서 비슷한 색으로 연결된 영역을 선택합니다. 모든 피사체를 이해하는 의미 기반 AI 보정은 아니므로 무늬나 대비가 약한 경계에서는 영역이 예상과 다를 수 있습니다. 크게 열린 캐릭터 윤곽도 완전히 복원한다고 보장하지 않습니다.

원본부터 투명한 곳에는 임의로 흰색을 채우지 않습니다. 원본 미리보기에도 체크무늬를 표시해 원래 투명도와 제거 결과를 구분합니다. 보정은 별도 Worker에서 실행되며, 색상 안내선은 저장 파일에 들어가지 않습니다. 되돌리기는 마지막 보정 1회만 저장하고 취소하면 편집 전 결과를 유지합니다. 적용한 PNG가 미리보기와 다운로드에 모두 반영됩니다. GIF는 프레임별 캐릭터 보호를 지원하지만 대화형 영역 보정은 PNG에서만 지원합니다.

단색이 아닌 배경에는 오류 안내와 함께 사진 AI 모드를 권합니다. 캐릭터 보호가 실패해도 조용히 AI로 전환해 내부를 다시 지우지 않습니다. 원본 파일은 그대로 유지됩니다.

## 처리 제한

| 항목 | 빠르게 | 꼼꼼하게 |
| --- | --- | --- |
| 사진 AI 모델 | IS-Net uint8 | IS-Net fp16 |
| 사진 긴 변 | 최대 2,048px | 최대 4,096px |
| GIF 긴 변 | 최대 768px | 최대 1,024px |

공통: 파일 최대 20MB, 사진 4,000만 화소, GIF 프레임당 400만 화소·최대 120프레임. 작은 이미지는 확대하지 않습니다. 애니메이션 WebP/APNG는 프레임 손실을 막기 위해 거절합니다. GIF의 256색·1비트 투명도 제한으로 경계가 거칠 수 있고 프레임별 AI 추론 결과에 차이가 있을 수 있습니다. 투명도는 128 기준으로 변환합니다. 배경색 변경은 미리보기 전용이며 저장 파일은 항상 투명합니다.

## 네트워크와 데이터

캐릭터 보호와 영역 보정에는 AI 모델 다운로드가 없습니다. 사진 AI 모드의 첫 처리 시 `https://staticimgly.com/@imgly/background-removal-data/1.7.0/dist/`에서 모델과 WASM 실행 파일을 내려받습니다. 빠르게 모델은 약 40MB, 꼼꼼하게 모델은 약 80MB이며 실행 파일 다운로드가 추가됩니다. 사진 AI에는 해당 도메인에 접근할 수 있어야 합니다. 이후에는 브라우저 캐시가 재사용됩니다. 글꼴은 jsDelivr에서 내려받으며 실패 시 시스템 글꼴을 사용합니다. 분석·광고·이미지 업로드 서버는 없습니다. 결과와 원본 Blob URL은 새 파일 선택 또는 페이지 종료 시 해제됩니다.

처리는 별도 Worker에서 실행되며 취소 시 Worker를 종료합니다. UI의 모델 다운로드 수치는 현재 다운로드 중인 자산의 진행률입니다. GIF는 프레임을 한 번에 하나씩 디코딩·처리·인코딩해 디코딩된 모든 프레임을 메모리에 보관하지 않습니다.
